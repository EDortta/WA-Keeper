# Tipografia

Preferência: Inter.

- Display / títulos: Inter Bold
- Seções: Inter SemiBold
- Corpo: Inter Regular
- Botões: Inter Medium / SemiBold
- Labels: Inter Medium

Escala recomendada:
- 28 px — título principal
- 22 px — título de tela
- 18 px — seção
- 16 px — corpo principal
- 14 px — corpo secundário
- 12 px — metadata
