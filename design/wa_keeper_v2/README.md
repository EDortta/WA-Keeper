# WA Keeper — Proposta visual v2

Pacote de referência para implementação manual na branch `development`.

## Objetivo
Diferenciar visualmente o WA Keeper do WhatsApp, mantendo a associação funcional sem copiar sua identidade.

Direção visual:
- azul profundo como cor principal;
- cyan para automação/inteligência;
- verde apenas para estados positivos;
- suporte completo a tema claro e escuro;
- ícones consistentes e profissionais;
- componentes reutilizáveis em Flutter;
- preservar toda a lógica existente do app.

## Estrutura
- `assets/app_icon/` — ícone proposto
- `assets/mockups/reference/` — referências visuais geradas
- `design_system/` — regras de cor, tipografia, espaçamento e ícones
- `flutter_reference/` — código Flutter de referência
- `COPILOT_IMPLEMENTATION.md` — instruções de implementação
- `navigation_flow.md` — mapa de telas

## Observação
Este pacote é uma referência de redesign. O Copilot deve reaproveitar serviços, modelos, permissões, armazenamento e automações existentes no projeto.
