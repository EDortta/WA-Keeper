# Roteiro de screenshots

Usar dados fictícios. Nenhum telefone, nome, foto, conversa ou documento real.

## Sequência proposta

1. **Suas conversas. Organizadas.**
   Tela principal com conversas e entidades.

2. **Encontre o que importa.**
   Busca com resultado visível.

3. **Ouça sem olhar para a tela.**
   Mensagem com ação de reprodução/TTS.

4. **Áudio também vira informação.**
   Áudio com transcrição.

5. **Organize do seu jeito.**
   Entidades e associações.

6. **Privacidade sob seu controle.**
   Configurações de retenção, voz, transcrição e armazenamento.

## Diretórios

- `screenshots/source/`: capturas originais.
- `screenshots/final/`: imagens prontas para upload.
- `screenshots/demo-data/`: roteiro dos dados fictícios usados.

## Regras

- não editar a interface para mostrar algo que o app não faz;
- não expor dados pessoais;
- não mostrar capacidades excluídas da variante Play;
- manter consistência visual entre todas as telas;
- registrar a versão do app usada para produzir cada conjunto.
